# MuseMusic 使用手册

## 1. 应用说明

MuseMusic 是一款 Android 本地音乐播放器。应用通过 Android MediaStore 读取手机中的音乐，不提供在线音乐播放、歌曲下载或流媒体服务。

歌曲和歌词应放在安装应用的 Android 设备中，无需复制到项目源码目录。

## 2. 导入歌曲

### 2.1 将歌曲复制到手机

通过 USB、文件管理器或其他文件传输工具，将音频文件复制到手机存储。建议使用以下目录：

```text
内部存储/Music/
```

例如：

```text
内部存储/Music/周杰伦/晴天.mp3
```

实际可播放格式由 Android 设备的系统解码能力决定，通常包括 MP3、FLAC、AAC、M4A、OGG 和 WAV。

### 2.2 授予读取权限

首次启动应用时，根据系统提示授予以下权限：

- Android 13 及以上：“音乐和音频”权限。
- 较早的 Android 版本：存储读取权限。

如果之前拒绝了权限，可以前往：

```text
系统设置 → 应用 → MuseMusic → 权限
```

允许应用访问音乐和音频文件。

### 2.3 扫描歌曲

正常情况下，应用会自动显示已经登记到 Android MediaStore 的本地歌曲。

如果歌曲没有出现：

1. 打开应用中的“文件夹（Folders）”页面。
2. 浏览到歌曲所在目录。
3. 点击尚未加入媒体库的歌曲。
4. 在提示中选择“扫描（Scan）”。
5. 等待扫描完成后返回歌曲列表。

也可以尝试重新启动应用或手机，让 Android 系统重新扫描媒体文件。

## 3. 导入歌词

应用支持普通歌词、LRC 时间轴歌词以及音频标签中内嵌的歌词。

### 3.1 同目录 LRC 歌词（推荐）

将 `.lrc` 文件放在歌曲旁边，并让歌词文件名与歌曲文件名完全一致：

```text
Music/
├── 周杰伦 - 晴天.mp3
└── 周杰伦 - 晴天.lrc
```

LRC 文件使用 UTF-8 编码。内容示例：

```lrc
[00:00.00]晴天
[00:12.50]故事的小黄花
[00:16.20]从出生那年就飘着
```

时间标签格式为 `[分钟:秒.毫秒]`。没有时间标签的文本只能作为普通歌词显示，无法随播放进度滚动。

### 3.2 专用歌词目录

同步歌词也可以放在：

```text
内部存储/RetroMusic/lyrics/
```

文件名必须使用以下格式：

```text
歌曲标题 - 艺术家.lrc
```

例如：

```text
内部存储/RetroMusic/lyrics/晴天 - 周杰伦.lrc
```

这里的歌曲标题和艺术家名称应与音频文件标签中记录的信息一致。

### 3.3 普通文本歌词

应用会在歌曲目录中查找文件名与歌曲文件名或歌曲标题匹配的 `.lrc`、`.txt` 文件。普通文本可以显示，但建议同步歌词统一使用 `.lrc` 格式。

### 3.4 内嵌歌词

如果音频文件的歌词标签中已经包含歌词，应用可以直接读取。带有 LRC 时间标签的内嵌歌词可以作为同步歌词显示。

## 4. 在应用内编辑歌词

1. 开始播放需要添加歌词的歌曲。
2. 打开播放器右上角菜单。
3. 选择“转到歌词（Go to lyrics）”。
4. 点击歌词页面右下角的编辑按钮。
5. 粘贴普通歌词或带时间标签的 LRC 歌词。
6. 点击“保存”。
7. Android 11 及以上系统如弹出写入确认窗口，请允许修改对应的歌曲或歌词文件。

歌词页面右上角的搜索按钮会打开网页搜索，不会自动下载或自动写入歌词。找到歌词后，需要复制并通过编辑按钮保存。

## 5. 显示歌词

播放歌曲后，可以通过播放器菜单进入完整歌词页面。播放器设置中还可以选择封面歌词的显示方式，例如覆盖封面或替换封面。

同步歌词会根据 LRC 时间标签跟随播放进度滚动；普通歌词仅以文本形式显示。

## 6. 常见问题

### 歌曲已经复制到手机，但列表中没有显示

- 确认已经授予音乐和音频读取权限。
- 确认文件不是隐藏文件，并且所在目录没有 `.nomedia` 文件。
- 在“文件夹”页面找到歌曲并执行扫描。
- 检查音频文件是否能被手机上的其他本地播放器正常识别。
- 重新启动应用或手机后再次检查。

### 歌词文件存在，但没有显示

- 确认歌词和歌曲位于同一目录。
- 确认两者的主文件名完全一致，例如 `晴天.mp3` 对应 `晴天.lrc`。
- 确认歌词文件采用 UTF-8 编码。
- 如果使用专用歌词目录，确认命名为“歌曲标题 - 艺术家.lrc”。
- 检查歌曲标题和艺术家标签是否正确。

### 歌词显示了，但不会滚动

普通文本歌词不会自动同步。需要使用包含时间标签的 LRC 歌词，例如：

```lrc
[01:24.30]这一句歌词将在 1 分 24.3 秒时显示
```

### 修改歌词时系统要求授权

这是 Android 对媒体文件写入操作的安全限制。确认目标文件正确后，在系统弹窗中允许本次修改即可。

## 7. 文件整理建议

建议按照艺术家和专辑整理歌曲，并为每首歌曲保留同名歌词：

```text
内部存储/Music/
└── 周杰伦/
    └── 叶惠美/
        ├── 晴天.mp3
        ├── 晴天.lrc
        ├── 东风破.mp3
        └── 东风破.lrc
```

规范的歌曲标题、艺术家和专辑标签可以提高歌曲分类、封面展示以及专用歌词目录匹配的准确性。
